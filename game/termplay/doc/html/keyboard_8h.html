std::string getKey ( )

Get a key from the keyboard. This is non-blocking. The result will be as follows:

  • If no key was pressed, an empty string is returned.
  • If a printable key was pressed, that key is returned as 1 character string.
  • Cursor keys: "up", "down", "left", "right"
  • Escape key: "esc"
    Returns
    std::string The key that was pressed.
